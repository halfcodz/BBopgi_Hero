# 뽑기키우기 (BBopgi Hero)

인형뽑기로 새끼 드래곤을 뽑고, 그 드래곤들이 스테이지를 돌며 모아 온 코인으로 다시 뽑는 방치형 수집 RPG.

- 엔진: Godot 4.7 (GDScript), 세로형 720×1280
- Godot 프로젝트: [`뽑기키우기/`](뽑기키우기) — Godot에서 이 폴더의 `project.godot`을 열고 F5
- 기획서: [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md)
- 밸런스 시뮬레이터: `python tools/balance_sim.py [시간] [시드]`

## 현재 들어간 기능 (M0 프로토타입)

| 기능 | 내용 |
|---|---|
| 자동 전투 | 웨이브 4 + 보스, 보스 제한시간, 드래곤 스킬, 속성 상성, 탭 공격, 피버 |
| 인형뽑기 | 집게 조작(◀ ▶ / 드래그 / 키보드), 퍼펙트 보너스, 휘청 연출, 10연 쓸어담기, 등급 승급 리빌, 천장, 기계 레벨, 확률 공시, 신화 마일리지 교환 |
| 드래곤 | 20종, 레벨업(꾹 누르면 연속), 별 승급 ★1~6 (외형 변화), 파티 5칸, 자동 편성, 도감 |
| 성장 | 둥지 이사(환생) → 용의 비늘 영구 배율 |
| 미션 | 일일 미션 4종 (오전 5시 초기화) |
| 저장 | 30초마다 자동 저장, 오프라인 보상 최대 8시간 |

아트는 아직 외부 에셋 없이 코드로 그린다 (`scripts/ui/dragon_art.gd`).
